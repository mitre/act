# Introduction to MITRE ACT™

MITRE Adaptive Cybersecurity Testing (ACT) helps organizations **decide which cybersecurity risks to address first and which to accept**. ACT draws on Risk Information Sources (RIS) to understand what the system does, which safeguards are working, and what could disrupt the mission.

Start with what you already have. Evidence that a requirement is met is as valuable as evidence that it is unmet. Running configurations, events reported in the news, and conflicts between requirements can also change how you understand a risk.

## Learn the process

1. [Why ACT Matters](/introduction/why-act-matters) shows how a disaster response team chooses what to fix first when it receives 137 findings.
2. [How ACT Works](/introduction/how-act-works) shows how the team combines different sources of evidence to make a decision.
3. [ACT in Practice](/introduction/act-in-practice) helps you choose an assessment approach and take the first steps.

## Use ACT today

Use the [manual templates and work aids](/templates) to plan, conduct, and report on an assessment. The [downloadable ACT Handbook](/templates#handbook-and-fact-sheet) walks through each phase.

[Agentic ACT](/agentic-act), planned for 2027, is being developed to help assessors work through evidence and draft risk statements for human review.
